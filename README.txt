Chemistry Trainer - Android向けPWA

【内容】
- 理論・有機・無機・分析・物理化学・実験化学の学習画面
- 短時間クイズと資料型の総合演習
- 解答・詳しい解説
- 正答率と苦手分野の端末内保存
- Service Workerによるオフラインキャッシュ

【Androidへのインストール】
1. このフォルダ一式をHTTPS対応のWebサーバーに置きます。
2. AndroidのChromeでそのURLを開き、最初にオンライン状態で読み込みます。
3. メニュー（︙）から「アプリをインストール」または「ホーム画面に追加」を選びます。
4. インストール後は、初回キャッシュ済みの画面・問題をオフラインで利用できます。

注意：PWAのインストールにはHTTPS配信（またはlocalhost）が必要です。ZIPファイルを直接開くだけではAndroidアプリとしてインストールできません。

【プライバシー】
学習履歴はブラウザのlocalStorageに保存され、外部送信しません。ブラウザのデータ消去・アプリ削除で記録が消えることがあります。
